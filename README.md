# 保育ナビ（仮）— 保育情報閲覧システム（仮名）

薩摩川内市の保育・子育ての情報を、保育者と保護者がそれぞれの立場で見られる見本のサイトです。

- **国・県・市の公開資料**：毎週自動で巡回し、Claude が索引カード（要約・見出し・キーワード）を作る。人が確かめてから公開
- **園内資料**：ログインした保育者だけが、手順書などを登録・閲覧できる（PDF・Word・Excel・テキスト）
- **市内の園**：54園の定員・1号の定員・保育時間・費用。写真はスライドショー（見本では仮の画像）
- **まとめてさがす**：トップの検索ボックス（マイク入力つき）で、保護者向け・保育者向けの資料と園をいっしょに探す。AIに要約してもらうこともできる
- **AIの案内役**：保護者向けの「ひなた」、保育者向けの「しおり」。サイトの資料だけを根拠に、出典つきで答える

つくり：GitHub Pages ＋ Supabase（DB・Auth・Storage・Edge Functions）＋ Claude API（claude-haiku-5-5）＋ GitHub Actions

設定の手順は [SETUP.md](SETUP.md) を見てください。

見本では、公開資料と架空の園の資料だけを使います。実在の園児や保護者の情報は入れません。
